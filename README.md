## Introduction
Welcome to my personal portfolio repository. This project demonstrates building a fully responsive, single-page web application from scratch using **Pure HTML and CSS**, without relying on any external frameworks (like Bootstrap). 

The portfolio features a modern **Dark Theme** UI and is structured to showcase my work, skills, and contact information seamlessly across all devices.

---

## Project Requirements & Features

This repository is structured to showcase the full web design process, from planning to responsive development:

### 1. Wireframe & Mockup
* **Folder Location:** `assets/`
* **Description:** Pre-development planning documents created using Miro to define the layout and visual identity before writing any code.
* **Files:** Contains the structural layout (`wireframe.png`) and the final visual design with the dark theme applied (`mockup.png`).

### 2. Semantic HTML Structure
* **File Location:** `index.html`
* **Coverage:** Utilizes semantic tags (`<header>`, `<nav>`, `<section>`, `<main>`, `<footer>`) for better accessibility and SEO.
* **Details:** Includes a Hero section, an About Me area, a Grid-based Projects showcase, and a fully structured Contact form.

### 3. Pure CSS Styling (No Frameworks)
* **File Location:** `style.css`
* **Details:** 
  * Implementation of **CSS Variables** (`:root`) for consistent color theming, spacing, and typography.
  * Advanced layout techniques utilizing **Flexbox** and **CSS Grid** to arrange elements cleanly.
  * Custom smooth scrolling and interactive hover effects.

### 4. Responsive Design (Media Queries)
* **Tool:** Pure CSS `@media` rules within `style.css`.
* **Coverage:** 
  * **Tablet (max-width: 992px):** Converts side-by-side flex layouts (e.g., About and Projects sections) into centered column layouts for better readability.
  * **Mobile (max-width: 768px):** Adapts the UI for small screens by hiding the header for a cleaner view, stacking grid project cards into a single column, and adjusting form paddings.
